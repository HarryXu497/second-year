# Introduction

Consider the function

```python
def an_E():
	if maybe():
        return one_of("x", "y", "z")
    else:
        e1, e2 = an_E(), an_E()
        return e1 + one_of("–", "∗") + e2
```

We want to describe the set $E$ of all possible strings that can be returned from `an_E`. Here, we define the set $E$ as follows.

1. $x, y, z \in E$.
2. For any $e_1, e_2 \in E$, both $e_1 - e_2$ and $e_1 * e_2$ are in $E$.

We want to generalize this pattern.

# Recursive Set Definitions

A **recursive/structural** definition of a set $X$ looks like the following.

1. **Base case**: $a, b, c, \ldots \in X$.
2. **Recursive part**: For any $x_1, \ldots, x_k \in X$, some transformations $f_1(x_1, \ldots, x_k), \ldots, f_n(x_1, \ldots, x_k) \in X$ 

For a particular element of $X$, we can perform a **derivation** for that element. For example, we can show that $x - z * x \in E$:

1. $x \in E$ (Base Case)
2. $z \in E$ (Base Case)
3. $x - z \in E$ (Recursive Case; $x, y \in E$)
4. $x - z * x \in E$ (Recursive Case; $x - z, x \in E$)

Note the bottom up structure and how no steps are repeated (e.g. $x \in E$ is only **proved** once). It is a condensed, bottom-up version of the derivation tree:

# Structural Induction

**Structural induction** is a method to prove a statement over all elements in a recursive set.

For a recursively defined set $X$, we want to show $\forall x \in X, P(x)$. Then,

1. Let $x \in X$.
2. If $x$ is a base case, show $P(x)$ directly.
3. Otherwise, $x$ is some transformation $f_i(x_1, \ldots, x_k)$. Show $P(x)$ assuming $P(x_1), \ldots, P(x_k)$

Given a particular recursively defined set, we can state a Structural Induction principle for the set it defines. For the definition of $E$, the corresponding **induction principle** is:

> Let $P$ be a predicate whose domain is a superset of $E$.
> If $P(x)$, $P(y)$, $P(z)$, and $\forall e_1, e_2 \in E, (P(e_1) \land P(e_2)) \implies (P(e_1 - e_2) \land P(e_1 * e_2))$, then $\forall e \in E, P(e)$.

## Example

Consider the set $E$ of all possible strings that can be returned from `an_E` above. We define the set $E$ as follows.

1. $x, y, z \in E$.
2. For any $e_1, e_2 \in E$, both $e_1 - e_2$ and $e_1 * e_2$ are in $E$.

Suppose we want to show that

> $\forall e \in E$, $e$ contains one more variable occurrence than operator occurrence.

> [!NOTE] Proof
> Let $e \in E$. Then, there are two cases:
> 
> **Case 1**. $e$ is a base case. There are three subcases:
> 
> **Subcase 1**. $e = x$: $e$ has one variable occurrence and no operator occurrences, as required.
> **Subcase 2**. $e = y$: $e$ has one variable occurrence and no operator occurrences, as required.
> **Subcase 3**. $e = z$: $e$ has one variable occurrence and no operator occurrences, as required.
> 
> **Case 2**. $e$ is the result of some transformation. There are two subcases:
> 
> **Subcase 1**. $e = e_1 - e_2$. Assume that $e_1$ has $n_1$ variable occurrences and $n_1 - 1$ operator occurrences. Assume that $e_2$ has $n_2$ variable occurrences and $n_2 - 1$ operator occurrences. 
> 
> Then, $e$ has $n_1 + n_2$ variable occurrences and $(n_1 - 1) + (n_2 - 1) + 1 = n_1 + n_2 - 1$ operator occurrences, as required.
> 
> **Subcase 2**. $e = e_1 + e_2$. Assume that $e_1$ has $n_1$ variable occurrences and $n_1 - 1$ operator occurrences. Assume that $e_2$ has $n_2$ variable occurrences and $n_2 - 1$ operator occurrences. 
> 
> Then, $e$ has $n_1 + n_2$ variable occurrences and $(n_1 - 1) + (n_2 - 1) + 1 = n_1 + n_2 - 1$ operator occurrences, as required.

# Derivational Ambiguity

Sometimes there are multiple ways to show a particular element is in the set. In this case, we'll say that the structural set definition is **derivationally ambiguous**.

For set $E$, consider $y - x - y$, which can be either $(y - x) - y$ or $y - (x - y)$.

Suppose we define a function $\mathrm{val}: E \to \mathbb{Z}$ by the following,

$$
\mathrm{val}(e) = \begin{cases}
1 & e \in \{x, y, z\} \\
\mathrm{val}(e_1) - \mathrm{val}(e_2) & e= e_1 - e_2 \text{ for some } e_1, e_2 \in E \\
\mathrm{val}(e_1) \cdot \mathrm{val}(e_2) & e= e_1 * e_2 \text{ for some } e_1, e_2 \in E \\
\end{cases}
$$

Then $\mathrm{val}(y - x - y)$ can equal either $(1 - 1) - 1 = -1$ or $1 - (1 - 1) = 1$.

To ensure that these recursive rules define a function, we can require each element to have a unique derivation tree. For example, we can instead define $E$ as

1. $x, y, z \in E$.
2. For any $e_1, e_2 \in E$, both $(e_1 - e_2)$ and $(e_1 * e_2)$ are in $E$.

By using tuples, we can ensure that $(x - y) - x$ and $x - (y - x)$ are different.

# Binary Trees

We define the set of binary trees $\mathrm{BT}$ as follows:

1. $\circ \in \mathrm{BT}$
2. For all $t_\ell, t_r \in \mathrm{BT}$, $(t_\ell, t_r) \in \mathrm{BT}$

A function that generates a binary tree in Python might look like

```python
def bt():
	if maybe():
		return None
	else:
		return (bt(), bt())
```

We define the height of a binary tree as

$$
h(t) = \begin{cases}
0 & t = \circ \\
1 + \max(h(t_\ell), h(t_r)) & t = (t_\ell, t_r)
\end{cases}
$$

Since we have a recursive definition of a set of binary trees, we can perform structural induction over it. To show $\forall t \in \mathrm{BT}, P(t)$, we show

1. **Base case**. Show $P(\circ)$
2. **Inductive step**. Assume $P(t_\ell), P(t_r)$ for arbitrary $t_\ell, t_r \in \mathrm{BT}$, and show $P((t_\ell, t_r))$ .

Say we want to show 

$$
\forall t \in \mathrm{BT}, \mathrm{nn(t)} \le 2^{h(t)}-1
$$

> [!NOTE] Proof
> Let $P(t)$ be the statement $nn(t) \le 2^{h(t)} - 1$. 
> 
> Let $t \in \mathrm{BT}$ be fixed. Then, we have the following cases:
> 
> **Base case**. By simple substitution, we have
> 
> $$
> nn(\circ) = 0 \le 0 = 2^{0} - 1
> $$
> 
> **Inductive step**. Let $t_\ell, t_r \in \mathrm{BT}$ be arbitrary. Assume $P(t_\ell), P(t_r)$:
> 
> $$
> \mathrm{nn}(t_\ell) \le 2^{h(t_\ell)} - 1 \text{ and } \mathrm{nn}(t_r) \le 2^{h(t_r)} - 1
> $$
> 
> By definition, we have $h(t) = 1 + \max(h(t_\ell), h(t_r))$, so we have
> 
> $$
> \begin{align*}
> &h(t) \ge h(t_\ell) + 1 \implies h(t_\ell) \le h(t) - 1 \text{ and } \\
> &h(t) \ge h(t_r) + 1 \implies h(t_r) \le h(t) - 1
> \end{align*}
> $$
> 
> Then, we have
> 
> $$
> \begin{align*}
> \mathrm{nn}(t) &= 1 + \mathrm{nn}(t_\ell) + \mathrm{nn}(t_r) \\
> &\le 1 + 2^{h(t_\ell)} - 1 + 2^{h(t_r)} \\
> &\le 1 + 2^{h(t) - 1} - 1 + 2^{h(t) - 1} \\
> &\le 2(2^{h(t) - 1}) - 1 \\
> &\le 2^{h(t)} - 1 \\
> \end{align*}
> $$
> 
> as required.
