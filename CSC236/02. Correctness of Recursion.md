# Introduction

Consider a country with only $3$ and $7$ dollar bills. Here are the quantities that we can make

| n   | 3   | 7   |
| --- | --- | --- |
| 0   | 0   | 0   |
| 1   |     |     |
| 2   |     |     |
| 3   | 1   | 0   |
| 4   |     |     |
| 5   |     |     |
| 6   | 2   | 0   |
| 7   | 0   | 1   |
| 8   |     |     |
| 9   | 3   | 0   |
| 10  | 1   | 1   |
| 11  |     |     |
| 12  | 3   | 0   |
| 13  | 2   | 1   |
| 14  | 0   | 2   |
| 15  | 4   | 0   |

Note a couple things:
1. Any number of the form $3a + 7b$, where $a, b \in \mathbb{N}$, can be formed
2. Any natural number $\ge 12$ can be formed; $12$, $13$, $14$ can be made, and every natural number greater is a multiple of $3$ greater than one of these numbers. This can be proved with **strong induction**.

> [!NOTE] Proof
> Let $P(n)$ be the statement that $\exists a, b \in \mathbb{N} \text{ s.t. } n = 3a + 7b$.  We want to show that $\forall n \in \mathbb{N}, n \ge 12, P(n)$ by the **strong principle of mathematical induction**.
> 
> **Base cases**:
> - $n = 12$. Take $a = 4$, $b = 0$. Then $n = 12 = 3(4) + 7(0) = 3a + 7b$
> - $n = 13$. Take $a = 2$, $b = 1$. Then $n = 12 = 3(2) + 7(1) = 3a + 7b$
> - $n = 14$. Take $a = 0$, $b = 2$. Then $n = 12 = 3(0) + 7(2) = 3a + 7b$
> 
> **Induction hypothesis**:
> Let $n \in \mathbb{N}, n \ge 14$ be fixed. Assume that $\forall k \in \mathbb{N}, 12 \le k \le n$, $P(n)$ holds. That is,
> 
> $$
> \forall k \in \mathbb{N}, 12 \le k \le n, \exists a, b \in \mathbb{N} \text{ s.t. } n = 3a + 7b
> $$
> 
> **Induction step**:
> We must show $P(n + 1)$:
> 
> $$
> \exists a, b \in \mathbb{N} \text{ s.t. } n + 1 = 3a + 7b
> $$
> 
> Note that $14 \le n \implies 12 \le n - 2 \le n$. Since $12 \le n - 2 \le n$, the induction hypothesis holds and we have
> 
> $$
> \exists a_1, b_2 \in \mathbb{N} \text{ s.t. } n - 2 = 3a_1 + 7b_1
> $$
> 
> Then, we have
> 
> $$
> n - 2 = 3a_1 + 7b_1 \implies n + 1 = 3(a_1 + 1) + 7b_1
> $$
> 
> Thus we have $a = a_1 + 3$ and $b = b_1$ such that $n + 1 = 3a + 7b$, as required.
> 
> Therefore, by the strong principle of mathematical induction, this statement is true. $\blacksquare$

```python
# Pre(n): n is a natural number and n >= 12
# Post(n): make_change(n) returns a, b s.t. 3a + 7b = n and a, b are natural numbers
def make_change(n: int) -> tuple[int, int]:
	if n == 12:
		return (3, 0)
	elif n == 13:
		return (2, 1)
	elif n == 14:
		return (0, 2)
	else:
		(t, s) = make_change(n - 3)
		return (t + 1, s)
```

# Correctness of Algorithms

In general, to prove the correctness of an algorithm, we must show that the preconditions imply the post conditions.

For recursive algorithms, we split up the proof into three steps:

1. Valid recursive structure
2. Correct return value
3. Valid non-recursive calls

## Valid Recursive Structure

We must show two conditions

1. **Valid call**. Every recursive call satisfies the preconditions
2. **Valid for recursion**. The input to every recursive structure is "smaller"

If a function satisfies both of these, then we say it has **correct recursive structure**.

To formalize the concept of a "smaller input", we define a function `size` that maps an input to the function to a natural number. If the recursive function $f$ takes input $I_1$ and calls itself with input $I_2$, we should have $\texttt{size}(I_1) > \texttt{size}(I_2)$.

We often show **valid recursion structure** by annotating code with comments. For example,

```python
# Pre(n): n in N and n >= 12
# Post(n): make_change(n) returns a, b s.t. 3a + 7b = n and a, b in N
# Let size(n) = n in N (by Pre)
def make_change(n: int) -> tuple[int, int]:
	if n == 12:
		return (3, 0)
	elif n == 13:
		return (2, 1)
	elif n == 14:
		return (0, 2)
	else: # (*) n >= 15
		# valid call:
			# WTS: Pre(n-3): n-3 in N and n - 3 >= 12
			# By Pre(n), n in N and n >= 12, so n - 3 in N
			# By (*), we have n >= 15 --> n - 3 >= 12
		# valid for recursion:
			# WTS: size(n) > size(n - 3)
			# size(n) = n > n - 3 = size(n - 3)
		(t, s) = make_change(n - 3)
		return (t + 1, s)
```

The general template for annotation code is

```python
# Pre(v): ...
# Return ...
# Let size(v) = ... in N because ...
def f(v):
	...
	# valid call:
	# Show prev(a)
	
	# valid for recursion:
	# Show size(v) > size(a) 
	f(a)
```

Consider the following example

```python
# Pre(a, b): a, b in N, a > 0
# Post(a, b): returns g such that g = gcd(a, b)
# Let size(a, b) = b in N (by Pre(a, b))
def g(a, b):
	if b == 0:
		return a
	else: # (*) b != 0 
		# valid call:
			# WTS: Pre(b, a % b): b, a % b in N and b > 0
			# By Pre(a, b), b in N
			# By (*) and Pre(a, b), a > 0 and b != 0, so a % b in N
			# By (*) and Pre(a, b), b in N and b != 0, so b > 0
		# valid for recursion:
			# WTS size(b, a % b) < size(a, b)
			# Since a in N and b > 0, a % b < b by quotient remainder theorem
		return g(b, a % b)
```

## Correct Return Value

A valid call to a recursive function returns the correct value if the following are true:

1. The function has a valid recursive structure (see the previous section)
2. The function returns the correct values **assuming all recursive calls return the correct values** i.e. all recursive calls satisfy their postconditions. If there are no recursive calls involved in the return value (e.g. in the base case), we just need to show that the return value is correct.

The assumption that all recursive calls return the correct values is called the **Recursive Hypothesis** (**RH**). 

We can reason about this from a **top-down** approach: all recursive calls eventually depends on the base case, which is correct. Or through a **bottom-up** approach: the base case is correct, so then next case is correct, and so on.

Thus, given a recursive function with valid recursive structure, we need to show that the recursive hypothesis implies that the function returns the correct values.

Once again, we show **correct return value** by annotating code:

```python
# Pre(n): n is a natural number and n >= 12
# Post(n): make_change(n) returns a, b s.t. 3a + 7b = n and a, b are natural numbers
def make_change(n: int) -> tuple[int, int]:
	if n == 12:
		return (4, 0)
		# Correct return:
			# WTS: Post(n)
			# 3(4) + 7(0) = 12 and 4, 0 in N
	elif n == 13:
		return (2, 1)
		# Correct return:
			# WTS: Post(n)
			# 3(2) + 7(1) = 13 and 2, 1 in N
	elif n == 14:
		return (0, 2)
		# Correct return:
			# WTS: Post(n)
			# 3(0) + 7(2) = 14 and 0, 2 in N
	else:
		# Assume RH: we have 3t + 7s = n - 3 and t, s in N
		(t, s) = make_change(n - 3)
		return (t + 1, s)
		# correct return:
			# WTS: 3(t+1) + 7s = n and t+1, s in N
			# By RH, we have 3t + 7s = n - 3
			# This implies 3(t+1) + 7s = n
			# By RH, we have t, s in N
			# This implies t+1, s in N
```

The general template is

```python
# Pre(v): ...
# Post(v): returns r s.t. ...
def f(v) :
	# Assume RH
	...
	f(a)
	# By RH, Post(a): returns r s.t. ....
	return e
	# correct return
	# [Show Post(v)]
```

## Valid Non-Recursive Calls

Once we've proven that a function has valid recursive structure and has correct return values, the only thing that remains is to check that everything else is also valid.

Therefore, we must check built-in Python functions, helper functions, operators etc. This can be very tedious.

```python
# Pre(n): n is a natural number and n >= 12
# Post(n): make_change(n) returns a, b s.t. 3a + 7b = n and a, b are natural numbers
def make_change(n: int) -> tuple[int, int]:
	# valid ==: n in N
	# valid "if": == returns a boolean
	if n == 12:
		return (4, 0)
	# valid ==: n in N
	# valid "if": == returns a boolean
	elif n == 13:
		return (2, 1)
	# valid ==: n in N
	# valid "if": == returns a boolean
	elif n == 14:
		return (0, 2)
	else:
		# valid -: n is a natural number
		# valid tuple assignment: by Post(n), make_change(n - 3) returns two natural numbers
		(t, s) = make_change(n - 3)
		
		# valid +: t is a natural number
		return (t + 1, s)
```

# Tracing

We trace `make_change(19)`:

```python
# Pre(19): 19 is a natural number and 19 >= 12
# Post(n): make_change(n) returns a, b s.t. 3a + 7b = n and a, b are natural numbers

	if n == 12:
		return (4, 0)
	elif n == 13:
		return (2, 1)
	elif n == 14:
		return (0, 2)
	else: # Execution enters else branch
		# Assume RH
		(t, s) = make_change(16)
		# By RH, we have Post(16): i.e. 3t + 7s = 16 and t, s in N
		return (t + 1, s)
		# Correct return:
			# WTS: Post(19) i.e. exists a, b s.t. 3a + 7b = 19 and a, b in N
			# Take a = t + 1, b = s
			# Then, 3a + 7b = 3(t+1) + 7s = 3t + 7s + 3 = 16 + 3 = 19
```

# Case Study: Prime Factorization

Recall that a prime number is a number that has no divisors other than $1$ and itself.

A prime factorization of a number $n$ is a sequence of numbers $a_0, \ldots, a_k$ such that $a_0 \times a_1 \times a_k= n$ such that each of $a_0, \ldots, a_k$ are prime.

We want to show the following claim:

> Every natural number $n \ge 2$ has a prime factorization.

Or formally,

$$
\forall n \in \mathbb{N}, n \ge 2 \implies \exists p_0, \ldots, p_m \in \mathcal{P}, n = \prod_{k=0}^m p_k
$$

where $\mathcal{P}$ is the set of prime numbers.

Consider the following solution:

```python
# Pre(n): n in N
# Returns b such that Post(b, n): b is a boolean and b iff n is prime.
def prime(n):
	if n < 2:
		return False
	for x in range(2, n):
		if n % x == 0:
			return False
		return True

# Pre(n): n in N and n is not prime
# Returns a, b such that Post(a, b, n): a, b in N, 2 <= a, b < n, n = ab
def two_factored(n):
	nums = list(range(2, n))
	for i in nums:
		if n % i == 0:
			return i, n//i

# =============================
# Pre(n): n >= 2 and n in N
# Returns (p_0,...,p_m) such that Post(p_0,...,p_m, n): p_0,...,p_m are prime and n = p_0p_1...p_m
def factored(n):
	if prime(n):
		return n,
	else: # Not prime
		f1, f2 = two_factored(n)
	
		return (*factored(f1), *factored(f2))
```

which we annotate as

```python
# Pre(n): n in N
# Returns b such that Post(b, n): b is a boolean and b iff n is prime.
def prime(n):
	if n < 2:
		return False
	for x in range(2, n):
		if n % x == 0:
			return False
		return True

# Pre(n): n in N and n is not prime
# Returns a, b such that Post(a, b, n): a, b in N, 2 <= a, b < n, n = ab
def two_factored(n):
	nums = list(range(2, n))
	for i in nums:
		if n % i == 0:
			return i, n//i

# =============================
# Pre(n): n >= 2 and n in N
# Returns (p_0,...,p_m) such that Post(p_0,...,p_m, n): p_0,...,p_m are prime and n = p_0p_1...p_m
# Let size(n) = n
def factored(n: int) -> tuple[int, ...]:
	# valid prime(n): n in N from Pre(n)
	# valid if: prime(n) returns a boolean
	if prime(n):
		return n,
		# Correct return:
			# n is already prime by the if branch and n = n
	else: # Not prime
		# Valid two_factored call:
			# WTS Pre_two_factored(n): n in N and n is not prime
			# From Pre(n), n in N
			# From the else branch, n is not prime
		f1, f2 = two_factored(n)
		# From Post_two_factored(f1, f2, n), f1, f2 in N, 2 <= f1, f2 < n, n = f1 * f2
	
		# Valid call:
			# WTS Pre(f1) and Pre(f2): f1 >= 2 and f2 >= 2
			# From the Post_two_factored(f1, f2, n),
				# f1 in N, f2 in N
				# f1 >= 2, f2 >= 2,
			# as required
		
		# Valid for recursion:
			# WTS size(n) > size(f1) and size(n) > size(f2)
			# From the Post_two_factored(f1, f2, n),
				# size(n) = n > f1 = size(f1) 
				# size(n) = n > f2 = size(f2)
			# as required
		
		# Assume RH: Post(q1, f1) and Post(q2, f2)
			# Post(q1, f1): q1 = (p_01, ..., p_m1) s.t. p_01, ..., p_m1 are prime and f1 = p_01...p_m1
			# Post(q2, f2): q2 = (p_02, ..., p_k2) s.t. p_02, ..., p_k2 are prime and f2 = p_02...p_k2
		q1 = factored(f1)
		q2 = factored(f2)

		return q1 + q2
		# Correct return:
			# WTS Post(q1 + q2, n): q1 + q2 = (p_01, ..., p_m1, p_02, ..., p_m2) s.t. p_01, ..., p_m1, p_02, ..., p_m2 are prime and n = (p_01...p_m1)(p_02...p_k2)
			# By RH, p_01, ..., p_m1, p_02, ..., p_k2 are prime
			# By
				# Post_two_factored(f1, f2, n): n = f1 * f2
				# RH: f1 = p_01...p_m1, f2 = p_02...p_k2
			# so n = (f1)(f2) = (p_01...p_m1)(p_02...p_k2) 
```
