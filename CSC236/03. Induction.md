# Complete/Strong Induction

Complete/strong induction is another way o prove the generic statement $\forall n \in \mathbb{N}, p(n)$.

On the real numbers, we describe this method of induction as

1. Let $n \in \mathbb{N}$.
2. For all $k \in \mathbb{N}, k < n, P(k)$. This is called the **induction hypothesis (IH)**
3. Show that $P(n)$

Let's say we want to show that

$$
\forall n \in \mathbb{N}, n \ge 12 \implies (\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = n)
$$

> [!NOTE] Proof
> 
> Take $n \in \mathbb{N}$. Let $P(n)$ be the statement $\forall n \in \mathbb{N}, n \ge 12 \implies (\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = n)$. Assume that
> 
> $$
> \forall k \in \mathbb{N}, k < n, P(k) \tag{IH}
> $$
> 
> Then, we have the following cases
> 
> 1. If $n < 12$, $P(n)$ is vacuously true.
> 2. If $n = 12$, pick $a = 4, b = 0$ so $3(4) + 7(0)= 12$.
> 3. If $n = 13$, pick $a = 2, b = 1$ so $3(1) + 7(1)= 13$.
> 4. If $n = 14$, pick $a = 0, b = 2$ so $3(0) + 7(2)= 14$.
> 5. If $n \ge 15$, we have $n - 3 \ge 12$, so by (IH), we have $a_0, b_0 \in \mathbb{N}$ such that $3a_0 + 7b_0 = n - 3$. Then, take $a = a_0 + 1 \in \mathbb{N}$ and $b = b_0 \in \mathbb{N}$ such that $3a + 7b = n$.
>
