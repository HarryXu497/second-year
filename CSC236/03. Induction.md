# Complete/Strong Induction

Complete/strong induction is another way to prove the generic statement $\forall n \in \mathbb{N}, p(n)$.

On the real numbers, we describe this method of induction as

1. Let $n \in \mathbb{N}$.
2. For all $k \in \mathbb{N}, k < n, P(k)$. This is called the **induction hypothesis (IH)**
3. Show that $P(n)$

Let's say we want to show that

$$
\forall n \in \mathbb{N}, n \ge 12, (\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = n)
$$

> [!NOTE] Proof
> 
> Take $n \in \mathbb{N}$. Let $P(n)$ be the statement $\forall n \in \mathbb{N}, n \ge 12, (\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = n)$. Assume that
> 
> $$
> \forall k \in \mathbb{N}, 12 \le k < n, P(k) \tag{IH}
> $$
> 
> Then, we have the following cases
> 
> 1. If $n = 12$, pick $a = 4, b = 0$ so $3(4) + 7(0)= 12$.
> 2. If $n = 13$, pick $a = 2, b = 1$ so $3(1) + 7(1)= 13$.
> 3. If $n = 14$, pick $a = 0, b = 2$ so $3(0) + 7(2)= 14$.
> 4. If $n \ge 15$, we have $12 \le n - 3 < n$, so by (IH), we have $a_0, b_0 \in \mathbb{N}$ such that $3a_0 + 7b_0 = n - 3$. Then, take $a = a_0 + 1 \in \mathbb{N}$ and $b = b_0 \in \mathbb{N}$ such that $3a + 7b = n$.

## Tracing

We can trace a complete induction proof similar to tracing a function. We list out the recursive tree of what each step depends on. For example, we can trace $P(19)$ in the above proof as

- $P(19)$: $\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = 19$
	- $P(16)$: $\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = 16$
		- $P(13)$: $\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = 13$

If the statement $P$ happens to be existential, the proof will produces certain witnesses. We can add these witnesses to the trace, which we will call a **trace with witnesses**.

- $P(19)$: $\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = 19$ is witnessed by $4, 1$
	- $P(16)$: $\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = 16$ is witnessed by $3, 1$
		- $P(13)$: $\exists a, b \in \mathbb{N} \text{ s.t. } 3a + 7b = 13$ is witnessed by $2, 1$

# Induction on a Measure

Consider binary trees. Let $\mathrm{BT}$ be the set of binary trees. Elements of $\mathrm{BT}$ are one of the following.

1. The empty node $\circ \in \mathrm{BT}$, or
2. A root node with a left child tree $l \in \mathrm{BT}$ and a right child tree $r \in \mathrm{BT}$.

We define the height of a binary tree as the number of levels containing nodes/non-empty subtrees. Recursively

$$
h(t) = \begin{cases}
0 & \text{if } t = \circ \\
1 + \max(h(l), h(r)) & \text{otherwise}
\end{cases}
$$

We want to find the maximum number of nodes in a tree of height $h(t)$. The claim we want to prove is that the number of nodes $\mathrm{nn}(t)$ of a tree $t$ is bound by

$$
\forall t \in \mathrm{BT}, \mathrm{nn(t)} \le 2^{h(t)}-1
$$

We can prove this by induction, but we need a variable to induct upon. In this case, we can perform complete induction on the height of the tree $t$. We want to show

$$
\forall n \in \mathbb{N}, \forall t \in \mathrm{BT}, h(t) = n \implies \mathrm{nn}(t) \le 2^n - 1
$$

> [!NOTE] Proof
> Fix $n \in \mathbb{N}$. Let $P(n)$ be the statement
> 
> $$
> \forall t \in \mathrm{BT}, h(t) = n \implies \mathrm{nn}(t) \le 2^n - 1
> $$
> 
> Assume that
> 
> $$
> \forall k \in \mathbb{N}, k < n, P(k) \tag{IH}
> $$
> 
> Then, we have the following cases
> 
> 1. $n = 0$. Let $t \in \mathrm{BT}$ . Assume $h(t) = n = 0$. Then, $t = \circ$. Thus, $\mathrm{nn}(\circ) = 0 \le 0 = 2^0 - 1$.
> 2. $n \ge 1$. Let $t \in \mathrm{BT}$ . Assume $h(t) = n \ge 1$. Since $h(t) \ge 1$, $t \ne \circ$ and thus $t$ has a left subtree $l \in \mathrm{BT}$ and a right subtree $r \in \mathrm{BT}$.
>    
>    These subtrees have
>    
>    $$
>    h(l) \le h(t) - 1 = n - 1 \quad \text{and} \quad h(r) \le h(t) - 1 =  n-1
> 	$$
>  
>    by definition. Since we have $n \ge 1$, we have $0 \le h(l), h(r) \le n - 1 < n$. This means that $h(l), h(r) \in \mathbb{N}$ and $h(l), h(r) < n$, so we can apply the induction hypothesis:
>    
>    $$
>    \begin{align*}
>    P(h(l))&: \forall t \in \mathrm{BT}, h(t) = h(l) \implies \mathrm{nn}(t) \le 2^{h(l)} - 1 \le 2^{n - 1} - 1 \\
>    
>    P(h(r))&: \forall t \in \mathrm{BT}, h(t) = h(r) \implies \mathrm{nn}(t) \le 2^{h(r)} - 1 \le 2^{n - 1} - 1
>    \end{align*}
>    $$
>    
>    Applying these hypotheses, we get
>    
>    $$
>    \mathrm{nn}(l) \le 2^{n - 1} - 1 \quad \text{and} \quad \mathrm{nn}(r) \le 2^{n - 1} - 1
>    $$
>    
>    Then, 
>    
>    $$
>    \begin{align*}
>    \mathrm{nn}(t) &= 1 + \mathrm{nn}(l) + \mathrm{nn}(r) \\
>    &\le 1 + (2^{n - 1} - 1) + (2^{n - 1} - 1) \\
>    &\le 2(2^{n - 1}) - 1 \\
>    &\le 2^n - 1 \\
>    \end{align*}
>    $$
>    
>    as required. $\blacksquare$

In general, if we want to show $\forall x \in D, P(x)$ using Complete Induction, we can define a size function $\mathrm{size}: D \to \mathbb{N}$ and then prove

$$
\forall n \in \mathbb{N}, \forall x \in D, (\mathrm{size}(x) = n \implies P(x))
$$

This essentially "partitions" values of $x$ by the value $\mathrm{size}$ and proves each possible value of $\mathrm{size}$.

In this case, we have 

$$
P'(x) \equiv \forall x \in D, (\mathrm{size}(x) = n \implies P(x))
$$

as the new statement we want to show.
