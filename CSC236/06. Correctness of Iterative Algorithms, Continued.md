# Review

Recall that to show correctness of iterative algorithms, we need to show

1. **Normal Termination**
	1. **Validity**. All calls are valid (so they terminate without errors)
	2. **Termination**. The iteration terminates
2. **Correct Return Value(s)**

We show this with loop invariants and variants:

1. A **loop invariant** is a claim about the variables that holds initially (after zero iterations) and at the end of each iteration.
2. A **loop variant** is a natural number, and strictly decreases with each iteration.

# Index of Minimum

Consider the algorithm

```python
# Pre(L,b) : L is a list of comparable elements, b in N, and b < len(L)
# Return m s.t. Post(m,L,b) : m in N, b <= m < len(L), and L[m] is the minimum of L[b:]
def index_of_minimal(L, b):
    m = b
    for i in range(b + 1, len(L)):
        if L[i] < L[m]:
	        m = i

    return m
```

We generally convert for loops to while loops.

```python
# Pre(L,b) : L is a list of comparable elements, b in N, and b < len(L)
# Return m s.t. Post(m,L,b) : m in N, b <= m < len(L), and L[m] is the minimum of L[b:]
def index_of_minimal(L, b):
    m_0 = b
    i_0 = b+1
    while i_k < len(L):
        if L[i_k] < L[m_k]:
            m_{k+1} = i_k
        else:
            m_{k+1} = m_k
        i_{k+1} = i_k + 1
    return m
```

We introduce some list notation:

- $L[n:m]$ means $[L[n], L[n+1], \ldots, L[m-1]]$.
- Let $[n: m]$ or $[n: m)$ mean the indices $[n, \ldots, m - 1]$.
- We extend $\le$ to lists in the following way: $L_1 \le L_2$ means that $\forall a \in L_1, \forall b \in L_2, a \le b$. If one side is a list and another side is a number, we'll treat the number as a singleton list.
- We place lists/slices/elements side by side to indicate concatenation.

# Designing an Invariant

We want to design an invariant that helps us prove the postcondition at the end of the loop. Also consider what is true after each iteration and what we need to be true so that the operations in the loop are valid.

For `index_of_minimal`, we want, for each value of $i_k$

1. $L[m] \le L[b:i]$
2. $b \le m < \mathrm{len}(L)$ (this is required in the postcondition)
3. $i \le \mathrm{len}(L)$
4. $m, i \in \mathbb{N}$

Ensure that, if we assume the invariant is true after the loop and we assume the negation of the loop condition, **we can prove the postcondition**.

Once you've come up with a proposed loop invariant, try the inductive step of the proof. If you get stuck somewhere, you might need to strengthen the loop invariant.

# Proof

We define $I_k(L, b, m_k, i_k)$ as

1. $L[m_k] \le L[b:i_k]$
2. $b \le m_k < \mathrm{len}(L)$ (this is required in the postcondition)
3. $b + 1 \le i_k \le \mathrm{len}(L)$ (the lower bound is required when we assign `m = i`)
4. $m_k, i_k \in \mathbb{N}$

```python
# Pre(L, b) : L is a list of comparable elements, b in N, and b < len(L)
# Return m s.t. Post(m, L, b) : m in N, b <= m < len(L), and L[m] is the minimum of L[b:]
def index_of_minimal(L, b):
	# WTS I_0
	# 1. L[m] = L[b] <= [L[b]] = L[b:b+1] = L[b:i_0]
	# 2. b <= b = m_0 < len(L) 
	# 3. By Pre(L, b), b < len(L). Also, i_0 = b+1.
	#    Then, i_0 = b + 1 < len(L) + 1 <= len(L)
	#    Thus, b + 1 <= i_0 <= len(L)
	# 4. By Pre(L, b), b in N, so m_0 = b in N and i_0 = b + 1 in N
    m_0 = b
    i_0 = b + 1
    while i_k < len(L):
	    # Assume I_k
		# 1. L[m_k] <= L[b:i_k]
		# 2. b <= m_k < len(L)
		# 3. b + 1 <= i_k <= len(L)
		# 4. m_i, i_k in N
		
		# Show I_{k+1}
		# 1. WTS: L[m_{k+1}] <= L[b:i_{k+1}]
		#    (if branch) If L[i_k] < L[m_k], then m_{k+1} = i_k.
		#    Since (I_k), L[m_k] <= L[b:i_k], we have
		#    L[i_k] < L[b:i_k] => L[m_{k+1}] < L[b:i_k].
		#    Also, L[m_{k+1}] = L[i_k]. Then, L[m_{k+1}] <= L[b:i_{k+1}]
		#    (else branch)  If L[i_k] >= L[m_k], then m_{k+1} = m_k.
		#    Then, by (I_k), L[m_{k+1}] = L[m_k] <= L[b:i_k].
		#    Also, L[m_{k+1}}] = L[m_k] <= L[i_k]
		#    Thus L[m_{k+1}] <= L[b:i_{k+1}]
		# 2. WTS: b <= m_{k+1} < len(L)
		#    (if branch) By (I_k) and (C), we have 
		#    b + 1 <= i_k < len(L). Then, since m_{k+1} = m_k,
		#    b + 1 <= i_k < len(L) => b <= m_k < len(L) 
		#    (else branch) Since m_{k+1} = m_k, and by (I_k),
		#    b <= m_k < len(L) => b <= m_{k+1} < len(L)
		# 3. WTS: b + 1 <= i_{k+1} <= len(L)
		#    By (I_k), b + 1 <= i_k <= len(L). Also, by (C), i_k < len(L)
		#    Then, b + 1 <= i_k + 1 <= len(L) => b + 1 <= i_{k+1} <= len(L), as required
		# 4. WTS: m_{i+1}, i_{k+1} in N
		#    i_{k+1} = i_k + 1 in N since i_k in N
		#    m_{k+1} = i_k or m_{k+1} = m_k
		#    Both are in N by (I_k)
        if L[i_k] < L[m_k]:
            m_{k+1} = i_k
        else:
            m_{k+1} = m_k
        i_{k+1} = i_k + 1
    # Assume I:
    # 1. L[m] <= L[b:i]
	# 2. b <= m < len(L)
	# 3. b + 1 <= i <= len(L)
	# 4. m, i in N
    # Assume !C: i >= len(L)
    # WTS: m in N, b <= m < len(L), and L[m] is the minimum of L[b:]
    # By (I_k), m in N and b <= m < len(L)
    # Also, since (I_k) i <= len(L) and (!C) i >= len(L), i = len(L)
    # Then, L[m] <= L[b:i] => L[m] <= L[b:len(L)] => L[m] <= L
    # as required.
    return m
```

# Variants

Last time, we defined a variant to be a natural number that decreases with each iteration.

Alternatively, we can allow variants to be increasing sequences of integers, as long as we show that it is bounded above. (hence the sequence is finite and the loop terminates).

Here, we can define the variant $V = i$, and show that $V$ is increasing with each iteration, and $V \le \mathrm{len}(L)$.

For for loops, we can apply a standard pattern.

## Standard Analysis of For Loops

In future proofs, we can take the analysis of for loops for granted i.e. if you see a for loop 

```python
for i in range(a, b):
	...
```

you can automatically assume $I^\mathrm{for}: i \in \mathbb{Z}, a \le i \le b$ holds, $i$ is initialized as $a$ before the loop and ends at $b$, and furthermore that the loop terminates.

# Indexless Notation

We can use a prime (') to indicate the next values in the loop both and leaving all other variable occurrences as-is.

A subscript with $0$ can still be used to indicate the starting value.

# Modifying Arguments

If the function modifies an argument, we can use subscripts to denote the successive states of the argument.

Consider

```python
# Pre(L_0): L_0 is a non-empty list of comparable elements
# Post(L, L_0): L has the same elements as L_0, sorted.
def sort ( L ) :
	for i in range (0, len(L) - 1):
		m = index_of_minimal(L, i)
		L[i], L[m] = L[m], L[i]
```
