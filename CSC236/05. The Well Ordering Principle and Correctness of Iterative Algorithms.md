# The Well Ordering Principle (WOP)

The **Well Ordering Principle** (**WOP**) states that every non-empty set of natural numbers has a minimum. That is,

$$
\forall S \subseteq N, S \ne \emptyset \implies \exists m \in S, \forall s \in S, m \le s
$$

Consider the quotient-remainder theorem:

$$
\forall n \in \mathbb{N}, d \in \mathbb{N}^+, \exists q, r \in \mathbb{N}, n = q \cdot d + r \land r < d
$$

We can prove it with the Well Ordering Principle as follows.

> [!NOTE] Proof
> Let $n \in \mathbb{N}$. Let $d \in \mathbb{N}^+$. Construct the set
> 
> $$
> R = \{r \in \mathbb{N}: \exists q \in \mathbb{N}, n = q \cdot d + r\}
> $$
> 
> Note that $R$ is not empty since we can always take $r = n, q = 0$ so
> 
> $$
> n = q \cdot d + r = 0 \cdot d + n = n
> $$
> 
> Since $R \subseteq \mathbb{N}$ and $R \ne \emptyset$, by WOP, $R$ has a minimum element $r_m \in R$. We want to show that $r_m < d$.
> 
> Suppose for contradiction that $r_m \ge d$. Then, since $r_m \in R$, $\exists q_m \in \mathbb{N}, n = q_m \cdot d + r_m$. But then,
> 
> $$
> \begin{align*}
> n &= q_m \cdot d + d + r_m - d \\
> &= (q_m + 1) \cdot d + (r_m - d) \\
> \end{align*}
> $$
> 
> Since
> 
> 1. we have $q = q_m + 1$ such that $n = q \cdot d + (r_m - d)$, and
> 2. $r_m \ge d \implies r_m - d \ge 0 \implies r_m - d \in \mathbb{N}$.
> 
> we have $r_m - d \in R$. But since $r_m - d < r_m$, $r_m$ is not the minimum of $R$, which is a contradiction.
> 
> Therefore, we have $r = r_m$ and the corresponding value of $q = n-r/d$ such that
> 
> $$
> n = q \cdot d + r
> $$
> 
> and $r < d$, as required. $\blacksquare$

## Generalizations

The Well-Ordering Principle does not apply to $\mathbb{R}$, $\mathbb{Q}$, or $\mathbb{Z}$. However, it does apply to certain subsets of $\mathbb{Z}$ beyond just the natural numbers. Formally,

> [!NOTE] Definition: Boundedness
> A set $S$ is **bounded below** if there is a number $b$ such that every element of $S$ is at least $b$. Similarly, $S$ is **bounded above** if there is a number $b$ such that every element of $S$ is at most $b$.
> 
> Then,
>  - Every non-empty subset of $\mathbb{Z}$ that is bounded below has a minimum.
>  - Every non-empty subset of $\mathbb{Z}$ that is bounded above has a maximum.

## Potentially Infinite Sequences

We can use the WOP to prove that recursion with valid recursive structure will terminate.

Let $f$ be a recursive algorithm and let $a_0$ be an input that satisfies the precondition. Let $f(a_0), f(a_1), \ldots$ be the sequence of recursive calls on a branch of execution.

Suppose $f$ has valid recursive structure. How can be we prove that the sequence $f(a_0), f(a_1), \ldots$ is not infinite?

Let $S$ be the size function that maps each input $a_i$ to a natural number. Since the sequence $S(a_0), S(a_1), \ldots$ form a non-empty set of natural numbers, it must have a minimum value $S_m$.

Also, the sequence $S(a_0), S(a_1), \ldots$ is strictly decreasing. Then, this sequence is bounded below by the minimum value $S_m$ and strictly decreasing. By the Monotone Convergence Theorem, this sequence converges to the infimum of $S(a_0), S(a_1), \ldots$, which equals the minimum in this case.

Thus, this sequence must be finite.

Since there is a one-to-one correspondence between $f(a_i)$ and $S(a_i)$, the sequence $f(a_0), f(a_1), \ldots$ must also be finite.

# Correctness of Iterative Algorithms

Consider the iterative algorithm

```python
# Pre(n, d): n in N and d in N^+
# Return q s.t. Post(q, n, d): q in N and there exists r in N, n = qd + r and r < d
def quotient(n, d):
	q = 0
	while n >= d:
		q = q + 1
		n = n - d
	return q
```

When working with iterative algorithms, the convention is to treat the values of a changing variable as a sequence of values at the end of each iteration. Include its initial value, which we think of as its value after zero iterations.

```python
# Pre(n_0, d): n_0 in N and d in N^+
# Return q s.t. Post(q, n_0, d): q in N and there exists r in N, n_0 = qd + r and r < d
def quotient(n_0, d):
	q_0 = 0
	while n_k >= d:
		q_{k+1} = q_k + 1
		n_{k+1} = n_k - d
	return q
```

We want to prove the correctness of this function. That is,

$$
\forall n_0, d, \mathrm{Pre}(n_0, d) \implies \mathrm{quotient}(n_d, d) \text{ returns a value } q \text{ with } \mathrm{Post}(q, n_0, d)
$$

We need to show the following.

1. **Normal termination**
	1. **Validity**. Each iteration is valid (so they terminate without errors).
	2. **Termination**. The iteration isn't a source of infinite execution
2. **Correct return value(s)**

## Validity and Loop Invariants

A **loop invariant** is a claim about the variables that hold initially (after zero iterations) and at the end of each iteration.

We can show **validity** using loop invariants. For the example above, note that the only operations in the loop body are $q = q + 1$ and $n = n - d$. To justify that each operation is valid, we need $q$ and $n$ to remain numbers. The precondition ensures that $d$ is a number and that $d$ never changes.

We define $I(n_0, d, q, n) = (n, q \in \mathbb{R})$ and $I_k(n_0, d, q_k, n_k) = (n_k, q_k \in \mathbb{R})$. 

The invariant claim is then

$$
\forall k \in \mathbb{N}, \text{if at least }k\text{ iterations have completed, then }I_k\text{ is true}
$$

We show this with annotations, in a recursive manner.

```python
# Pre(n_0, d): n_0 in N and d in N^+
# Return q s.t. Post(q, n_0, d): q in N and there exists r in N, n_0 = qd + r and r < d
def quotient(n_0, d):
	# WTS I_0: n_0, q_0 in R 
	# By Pre(n_0, d), n_0 in N^+ => n_o in R
	# Trivially, q_0 = 0 in R
	q_0 = 0
	
	while n_k >= d:
		# Assume I_k: n_k, q_k in R.
		# WTS: I_{k + 1}: n_{k+1}, q_{k+1} in R
		# By I_k, q_k in R, so q_{k+1} = q_k + 1 in R
		# By I_k and Pre(n_0, d) n_k in R and d in N^+, so n_{k+1} = n_k - d in R
		q_{k+1} = q_k + 1
		n_{k+1} = n_k - d
	return q
```

Note that this is essentially a proof by induction, but with $I_k$ instead of the induction hypothesis. We showed that $\mathrm{Pre} \implies I_0$ and that, for every $k \in \mathbb{N}$, if at least $k$ iterations have completed, then

$$
(C_k \land I_k) \implies I_{k + 1}
$$

Here $C_k$ is the loop condition after $k$ iterations. Note that $C_k$ being true means the $k+1$th iteration runs. It was not used for this particular proof.

## Termination

To show termination, we define a **loop variant**, which is similar to a notion of size for recursive functions. It is a natural number, and strictly decreases with each iteration.

For the `quotient` function, we define

$$
V_k = V(n_0, d, q_k, n_k) = n_k
$$

to be the value of $V$ after the $k$th iteration. We need to show that

1. $V$ is always a natural number: $\forall k \in \mathbb{N}$, if at least $k$ iterations have completed, $V_k \in \mathbb{N}$.
2. $V$ strictly decreases: $\forall k \in \mathbb{N}$, if at least $k + 1$ iterations have completed, $V_{k + 1} < V_k$.

We again show this with annotations, with a similar recursive structure as above

```python
# Pre(n_0, d): n_0 in N and d in N^+
# Return q s.t. Post(q, n_0, d): q in N and there exists r in N, n_0 = qd + r and r < d
def quotient(n_0, d):
	# WTS: V_0 = n_0 in K
	# By Pre(n_0, d), n_0 in N. 
	# Thus, V_0 = n_0 in N
	q_0 = 0
	
	while n_k >= d:
		# Assume V_k = n_k in N
		
		# WTS: V_{k+1} = n_{k+1} in N
		# By assumption, n_k in N. By Pre(n_0, d), d in N^+
		# Also, by C_k, n_k >= d. Then n_k - d >= 0 and thus
		# n_{k+1} = n_k - d in N
		
		# WTS: V_{k+1} = n_{k+1} < n_k = V_k
		# By Pre(n_0, d), d in N^+ and thus d >= 1
		# Then, n_{k+1} = n_k - d => n_{k+1} < n_k
		q_{k+1} = q_k + 1
		n_{k+1} = n_k - d
	return q
```

In particular, we show that $\mathrm{Pre} \implies V_0 \in N$ and that, for every $k \in \mathbb{N}$, if at least $k$ iterations have completed, then

$$
(C_k \land V_k \in \mathbb{N}) \implies (V_{k+1} \in \mathbb{N} \land V_{k+1} < V_k)
$$

## Correct Return Value

We also prove correctness of the return value using an invariant. 

For `quotient`, we define 

$$
I(n_0, d, q, n) \equiv (n, q \in \mathbb{N} \land n_0 = q \cdot d + n)
$$

and

$$
I_k(n_0, d, q, n) \equiv (n_k, q_k \in \mathbb{N} \land n_0 = q_k \cdot d + n_k)
$$

We want to show that $\forall k \in \mathbb{N}$, if at least $k$ iterations have completed, $I_k$ is true.

The invariant and the loop exit together imply the post condition:

$$
\mathrm{Pre} \implies ((I \land \neg C) \implies \mathrm{Post})
$$

We again show this with annotations

```python
# Pre(n_0, d): n_0 in N and d in N^+
# Return q s.t. Post(q, n_0, d): q in N and there exists r in N, n_0 = qd + r and r < d
def quotient(n_0, d):
	# WTS I_0: n_0, q_0 in N and n_0 = q_0 * d + n_0
	# By Pre(n_0, d), n_0 in N. 
	# Trivially, q_0 = 0 in N.
	# Since q_0 = 0, n_0 = 0 * d + n_0 = n_0
	q_0 = 0
	
	while n_k >= d:
		# Assume I_k: n_k, q_k in N and n_0 = q_k * d + n_k
		
		# WTS: I_{k+1}: n_{k+1}, q_{k+1} in N and n_0 = q_{k+1} * d + n_{k+1}
		# By I_k, n_k in N. By Pre(n_0, d), d in N^+. By C_k, n_k >= d.
		# Then, n_k - d >= 0 and thus n_{k+1} = n_k - d in N
		# By I_k, q_k in N. Then, q_k + 1 in N
		# By I_k, n_0 = q_k * d + n_k. Then,
		# n_0 = (q_k + 1 - 1) * d + n_k
		# n_0 = (q_k + 1) * d - d + n_k 
		# n_0 = (q_k + 1) * d + (n_k - d)
		# n_0 = q_{k+1} * d + n_{k+1}
		# as required
		q_{k+1} = q_k + 1
		n_{k+1} = n_k - d
	
	# By !C, n < d. Also, assume I: n, q in N and n_0 = q * d + n
	# Then, with r = n < d, n_0 = q * d + r, as required
	return q
```

We ended up showing three invariants in the proof

1. $n, q \in \mathbb{R}$
2. $n \in \mathbb{N}$
3. $n, q \in \mathbb{N} \land n_0 = q\cdot d + n$

We could have combined these into a single invariant. When showing $I_k \implies I_{k+1}$, you get to assume all parts of the invariant $I_k$, and part 1 of an invariant might help prove part 2 of the invariant and vice versa.

Also, **use all variables**. In most cases, the combined invariant depends on all the variables (otherwise they could have been removed from the function).

In summary, we've basically shown the following simple induction proof.

> [!NOTE] Summary
> Define $P(k)$: if there are at least $k$ iterations, then $I_k$.
> 
> $$
> \forall n_0, d, \mathrm{Pre}(n_0, d) \implies \forall k, P(k)
> $$
