# Formal Languages

Formal languages are defined with sets of strings. Thus, we establish some conventions

- A set of possible characters is called an **alphabet**; we typically use $\Sigma$ to denote the alphabet.
- A **string** over $\Sigma$ is a finish sequence of elements in $\Sigma$.
- We omit quotation marks around string literals and constants.
- We use $\varepsilon$ to denote the empty string.
- If $x$ and $y$ are variables denoting strings, we write $xy$ to mean their concatenation.
- The length of a string $s$ is notated at $|s|$.
- Let $\Sigma^*$ denote the set of all strings over the alphabet $\Sigma$.
- If $n \in \mathbb{N}$, let $\Sigma^n$ denote the set of strings of length $n$ over the alphabet $\Sigma$.
- A language (over $\Sigma$) is a set of strings over $\Sigma$ i.e $A$ is a language over $\Sigma$ if $A \subseteq \Sigma^*$.

# Regular Expressions

Regular expressions are used a lot in programming e.g. with `grep`

```bash
grep - E 'cat|dog' animals.txt
```

The notation used in languages or shells differ from our notation.

Let $\Sigma$ be an alphabet, Then $\mathcal{R}_\Sigma$, the set of regular expressions over $\Sigma$ is defined as follows

1. $\emptyset \in \mathcal{R}_\Sigma$
2. $\varepsilon \in \mathcal{R}_\Sigma$
3. $c \in \mathcal{R}_\Sigma$ for $c \in \Sigma$
4. If $R, S \in \mathcal{R}_\Sigma$, then
	1. $(R^*) \in \mathcal{R}_\Sigma$ (Kleene star)
	2. $(R \cdot S) \in \mathcal{R}_\Sigma$ (Concatentation)
	3. $(R + S) \in \mathcal{R}_\Sigma$ (Union)

For example, if we have $\Sigma = \{a, b\}$, we have 

1. $a \in \mathcal{R}_\Sigma$
2. $(a+(b^*)) \in \mathcal{R}_\Sigma$

To reduce the number of parentheses, we use the following rules:

1. $*$ before $\cdot$ before $+$.
2. Also, we remove $\cdot$

For example

$$
(a + (b \cdot (c^*))) \mapsto a+bc^*
$$

For each $R \in \mathcal{R}_\Sigma$, we define the associated language that $R$ **matches** as $\mathcal{L}(R)$ over $\Sigma$. The function $\mathcal{L}$ is recursively defined as follows.

1. $\mathcal{L}(\emptyset) = \emptyset$
2. $\mathcal{L}(\varepsilon) = \{\varepsilon\}$
3. $\mathcal{L}(c)= \{c\}=$ for $c \in \Sigma$
4. If $R, S \in \mathcal{R}_\Sigma$, then
	1. $\mathcal{L}((R^*)) = \{s_1\cdots s_k: k \in \mathbb{N}, s_1, \ldots, s_k \in \mathcal{L}(R)\}$
	2. $\mathcal{L}((R \cdot S)) = \{xy: x \in \mathcal{L}(R), y \in \mathcal{L}(S)\}$
	3. $L((R + S)) = \mathcal{L}(R) \cup \mathcal{L}(S)$

If $s \in \mathcal{L}(R)$, we say that $R$ **matches** $s$.

Let $\Sigma = \{a, b, c\}$. Then, the regular expression $R = (a + b + c)^*$ has $\mathcal{L}(R) = \Sigma^*$:

$$
\begin{align*}
\mathcal{L}((a + b + c)^*) &= \{s_1\cdots s_k: k \in \mathbb{N}, s_1,\ldots,s_k \in \mathcal{L}(a + b + c)\} \\
&= \{s_1\cdots s_k: k \in \mathbb{N}, s_1,\ldots,s_k \in \{a, b, c\}\} \\
&= \{s_1\cdots s_k: k \in \mathbb{N}, s_1,\ldots,s_k \in \Sigma\} \\
&= \Sigma^*
\end{align*}
$$
